# Olympus Elements Skill

## Overview
This skill provides a comprehensive WordPress plugin `olympus-elements` that extends Elementor with a suite of 10 custom "Nested Elements" widgets. These widgets are designed to recreate the OLYMPUS divine interface with full editability in the Elementor page builder.

## Key Features
- **Nested Elements**: All widgets extend `Widget_Nested_Base`, allowing them to act as containers for other Elementor elements.
- **GSAP Animations**: Integrated ScrollTrigger and reveal animations for high-end visual polish.
- **Full Editability**: Every text, color, typography, background, and JS parameter (durations, speeds) is exposed as an Elementor control.
- **Performance**: Optimized asset loading and Elementor frontend hooks for smooth performance in both editor and frontend.

## Included Widgets
1. `01-header`: Sticky logo and menu with reveal logic.
2. `02-loader`: Immersive loading screen with custom duration.
3. `03-hero`: Video scrub-controlled hero section.
4. `04-intro`: Animated quote and intro section.
5. `05-meander`: SVG-based Greek meander divider.
6. `06-pantheon`: Interactive god cards grid.
7. `07-myths`: Flippable myth pair sections.
8. `08-oracle`: Immersive oracle quote section.
9. `09-chronicles`: Responsive vertical timeline.
10. `10-footer`: Styled footer with navigation links.

## Usage
Activate the `Olympus Elements` plugin in WordPress. All widgets will be available under the "Olympus" category in the Elementor editor.
