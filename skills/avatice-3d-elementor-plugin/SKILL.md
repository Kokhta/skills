# Avatice 3D Elementor Plugin

Add an advanced 3D scroll-driven experience to Elementor.

## When to Use

Use this plugin when you want to create a high-end, immersive 3D scroll-driven design for a WordPress site using Elementor. It provides a master canvas widget and several content section widgets that integrate with a Three.js scene.

## Examples

- Interactive hero sections with 3D models.
- Strategy and service pages with 3D icons flying through a tunnel.
- Portfolio and testimonial sections with custom 3D transitions.

## Limitations

- Requires Elementor to be installed and activated.
- Best experienced on modern browsers with WebGL support.
- Performance may vary on very old hardware.
